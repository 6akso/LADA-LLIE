## 📅 Release Plan

> **The model implementation, pretrained weights, and complete training, inference, and evaluation code for LADA-LLIE will be open-sourced upon acceptance of the paper.**

This repository will serve as the official location for the public release of **LADA-LLIE**. Instructions for installation, model preparation, training, inference, and evaluation will accompany the released resources.

🔔 **Stay updated:** Watch this repository for release announcements and future updates.

<a id="documentation"></a>

## 📖 Documentation

Documentation will be provided alongside the code and model weights, covering:

- **Getting started** — Environment setup and dependency installation.
- **Data preparation** — Expected directory structure and input formats.
- **Model preparation** — Downloading and loading pretrained weights.
- **Training** — Configuration options and commands for running training.
- **Inference** — Instructions for processing input images and saving results.
- **Evaluation** — Commands and settings for evaluating model outputs.
